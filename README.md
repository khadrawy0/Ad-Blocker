# AdShield: حاجب إعلانات خفيف (DNS محلي)

## الفكرة
- VPN محلي على جهازك فقط (مفيش سيرفر خارجي).
- الـ VPN بيوجّه **عنوان DNS واحد فقط** للتطبيق (`addRoute(dns, 32)`)، يعني باقي النت (تصفح، ألعاب، فيديو) مش بيعدّي عليه وسرعتك ما بتتأثرش.
- أي استعلام DNS لنطاق إعلاني بنرد عليه `0.0.0.0`، فالإعلان مش بيتحمّل أصلاً.
- باقي الاستعلامات بتتبعت لـ DNS حقيقي (`1.1.1.1`) وبيرجع الرد زي ما هو.
- مفيش dependencies خارجية، فالـ APK صغير جداً. القراءة blocking (من غير polling) فالاستهلاك وقت الخمول صفر تقريباً.

## البناء
المتطلبات: Android Studio (أو Android SDK + Gradle 8.7+) وJDK 17.

1. افتح مجلد `AdShield` في Android Studio ← Sync.
2. وصّل موبايلك (USB debugging) واضغط Run، أو من الأوامر:
   `gradle assembleRelease`
   وهتلاقي الـ APK في `app/build/outputs/apk/release/`.
3. شغّل التطبيق ← "تشغيل" ← وافق على نافذة VPN (أول مرة بس).
4. اضغط "تحديث قائمة الحجب" مرة عشان تنزل قائمة كاملة (StevenBlack).

## لازم تعرف
- **Private DNS لازم يكون مقفول** (Settings ← Network ← Private DNS ← Off أو Automatic)، وإلا أندرويد هيتخطى الفلتر.
- أندرويد بيسمح بـ VPN واحد بس في نفس الوقت.
- بيحجب الإعلانات اللي جاية من شبكات إعلانية على نطاقات منفصلة (زي إعلانات لودو). مش هيحجب إعلان جاي من نفس نطاق المحتوى (زي يوتيوب).
- ألعاب كتير هتسيب مساحة الإعلان فاضية، وإعلانات "شوف إعلان وخد مكافأة" ممكن ما تدّيش المكافأة.
- IPv4 فقط حالياً (شبكات IPv6-only محتاجة تعديل).
- الأقسام اللي اتختبرت فعلياً: تحليل وبناء حزم DNS/UDP وchecksum وقراءة القوائم (راجع `test/`). الجزء اللي بيتعامل مع النظام (VpnService) محتاج تجربة على جهاز حقيقي.
